# ROBOT DEVELOPMENT REPORT #2

01~04 개발 계획에 이어 05~07 활동만 작성하는 GitHub Pages용 정적 웹 프로그램입니다.

## 포함 활동
- 05. 설계와 제작 과정
- 06. 시험과 개선
- 07. 개발 결과와 성찰

## 기능
- 01~04 프로그램에서 저장한 JSON 불러오기
- 설계 스케치/완성 사진 첨부(PNG, JPG, WEBP, 5MB 이하)
- 시험 항목 1~6개 추가·삭제
- 임시 저장, JSON 백업, A4 PDF 출력
- DOS/CRT 반응형 인터페이스와 F1/F2/F3/F4/F6 단축키

## 실행과 배포
`index.html`을 브라우저에서 열면 바로 실행됩니다. GitHub Pages에서는 두 파일을 저장소 루트에 올리고 Settings > Pages에서 main 브랜치 root를 선택합니다.

## 개인정보 및 제한
데이터는 브라우저 내부에서 처리되며 외부 전송되지 않습니다. 이미지가 크면 브라우저 localStorage 한도로 임시 저장이 실패할 수 있으므로 축소 이미지를 권장합니다.
